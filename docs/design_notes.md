# Design notes and visual QA log

Design decisions, and what visual QA found and changed. See spec Section 9 (the "field instrument" look, with the ear tag as the signature element).

## Decisions

| Date | Decision | Why |
|---|---|---|
| 2026-09-28 | Project name **PashuSetu (पशुसेतु)** replaces "PashuRakshak" from the spec | Team decision. "Setu" means bridge, between farmers, vets and officers |
| 2026-09-28 | Fonts: Mukta (text) + Anek Devanagari (display), bundled TTFs | Both are OFL. Anek Devanagari covers Latin too (checked with fontTools), so we don't need Anek Latin |
| 2026-09-28 | Anek weight/width set via `FontVariation` | It ships as one variable font (wght 100–800, wdth 75–125). Numbers use wdth 90 for a slightly condensed look |
| 2026-09-28 | Devanagari styles force line height ≥ 1.5 | Matras get clipped at tighter line heights (spec 9.4) |
| 2026-09-29 | Pictograms are generated by `mobile/tool/pictograms.py` from shared parts (cow body, cow head close-up, hen, udder, hoof) | 34 icons in one style. Strokes use `currentColor`, so selected tiles turn them white; the highlight stays `indigoTint` |
| 2026-09-29 | Head-area symptoms use a cow-head close-up; poultry symptoms use a hen or hen-head close-up | At 48 px a whole animal is too small to show drool, tears or a swollen comb |
| 2026-09-29 | Icons: Lucide (outline, 2 px strokes) | Matches the pictogram stroke weight; one icon set everywhere |
| 2026-09-29 | Primary buttons (Log in, Continue) are ink; only Report uses tag yellow | Keeps yellow for ear tags, the app mark and the one Report action (spec 9.2) |
| 2026-09-29 | Vet/officer KPIs in Phase 3 are counts from the live case queue (open, emergency, urgent, waiting for vet) | Alerts, median response time and lab KPIs need the Phase 8 dashboard; no invented numbers |
