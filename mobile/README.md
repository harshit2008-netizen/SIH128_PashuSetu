# mobile/ — PashuSetu Android app (Flutter)

One app with role-based homes: farmer, pashu sevak, vet, lab, district officer.

- `lib/core/`:
  - `theme/`: design tokens and typography.
  - `db/`: drift tables (outbox, caches, settings). Run `dart run build_runner build` after editing them.
  - `api/`: dio client and the online check.
  - `settings/`, `router/`, `shared_data/`: settings, routes, and loading of the shared JSON.
- `lib/widgets/`: the design-system components (spec 9.7). Screens import `widgets.dart`.
- `lib/features/`: screens by feature (auth, home, settings; report and triage arrive in Phase 4).
- `lib/l10n/`: `app_en.arb`, `app_hi.arb`, `app_mr.arb`. Hindi and Marathi are flagged for native review.
- `assets/pictograms/`: generated by `python tool/pictograms.py`. Open `tool/pictograms_preview.html` to review them.
- `assets/shared/`: a copy of `../shared` made by `make sync-shared`. Never edit it here.
- `test/goldens/`: screenshots in English and Hindi, 360 and 412 px wide, text scale 1.0 and 1.3. After an intended visual change, run `flutter test --update-goldens test/goldens`.

## Run on a phone connected by USB

```bash
make api                              # from the repo root, on the laptop
adb reverse tcp:8000 tcp:8000         # phone's 127.0.0.1:8000 -> laptop
flutter run
```

On a hotspot without USB: settings, tap the version 7 times, open Developer options, then set the API base URL to the laptop's IP (e.g. `http://192.168.43.10:8000`). The Android emulator uses `http://10.0.2.2:8000`.
